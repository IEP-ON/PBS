# 제46회 대구광역시 교육자료전 — PBS 플랫폼 출품 계획

> 이 문서는 공문 요강을 바탕으로 PBS 앱의 출품 전략과 제출 일정을 정리한 내부 작업 문서입니다.

---

## 출품 개요

| 항목 | 내용 |
|---|---|
| **출품 분야** | ⑪ 특수교육 |
| **자료 형태** | WBI 자료 (인터넷 기반) + 모바일 자료 (태블릿PC 기반) |
| **자료명(안)** | 특수학급 긍정적 행동지원(PBS) 실행을 위한 토큰경제 웹 자료 |
| **적용 학교급** | 초등학교 (특수학급) |
| **적용 교과** | 특수교육 (긍정적 행동지원 / 사회적응) |
| **적용 학년** | 전 학년 (특수학급 대상학생) |
| **주자료** | WBI 자료 (웹앱: PBS 플랫폼) |
| **보조자료 1** | 모바일 자료 (학생용 ATM·가게·일기 키오스크 PWA) |
| **보조자료 2** | 파일자료 (행동계약서·자료제작 설명서) |

## 심사 기준 대응 전략

| 심사 기준 | 배점 | PBS 앱 대응 포인트 |
|---|---|---|
| 자료의 적절성 | 20점 | 2022 개정 특수교육 교육과정 사회적응·일상생활 교과와 직접 연계; PBS 다층 지원(1~3차)을 단일 자료로 통합 지원; 행동 기능(SEAT) 기반 개별화 목표 설정 |
| 창의성 | 20점 | 토큰경제를 화폐·금융 시스템(ATM·가게·주식)으로 시각화하여 자기결정력과 행동 강화를 동시 구현; AI가 FBA 분석·중재 전략을 실시간 보조 제안 |
| 완성도 | 20점 | 실서비스 배포(Vercel) 운영 중; 교사·학생·키오스크 역할 분리 인터페이스; 소거 폭발 감지 알림 등 행동주의 이론 충실 반영 |
| 교육에의 기여도 | 20점 | 실제 학급 적용 데이터(행동 빈도 변화, 토큰 획득률 추이) 제시; 즉각적 강화 제공으로 중재 피드백 루프 단축; 교사 수기 기록 → 디지털 자동화로 중재 일관성 확보 |
| 일반화 가능성 | 20점 | 학급 식별코드 방식으로 추가 설치 없이 타 학교 특수교사 즉시 사용; PWA로 오프라인 환경 대응; 사용 가이드 영상 제작 및 에듀나비·에듀넷 공개 예정 |

## 교육자료 설명서 목차 (초안)

```
제목: 특수학급 긍정적 행동지원(PBS) 실행을 위한 토큰경제 웹 자료

Ⅰ. 자료 제작의 필요성 및 목적
   1. 자료 제작의 필요성
      - PBS는 예방·교수·강화의 일관된 실행이 효과의 핵심이나,
        특수학급 교사 1인이 즉각적 강화·실시간 기록·데이터 기반 결정을
        동시에 수행하기 구조적으로 어려움
      - 토큰경제는 80년 이상 검증된 강화 절차이나, 수기 운영 시
        즉시성과 일관성 확보가 어려움 (PMC/BACB, 2023)
   2. 자료 제작의 목적
      - PBS 1~3차 지원을 단일 디지털 자료로 통합 실행
      - 토큰경제를 통한 즉각적·일관된 강화 제공 자동화
      - FBA 기반 AI 보조 제안으로 교사의 중재 전략 결정 지원

Ⅱ. 자료 제작의 과정
   1. 제작 기간 및 절차 (2026.03 ~ 2026.06)
   2. 문헌 연구
      - PBS 다층 지원 체계 (Horner & Sugai, 2010; PBIS.org)
      - 토큰경제 근거 (PMC10700257, 2023)
      - 행동 기능 SEAT 모델 (BACB Task List 6th)
      - 소거 폭발 (PMC9868065, 2023)
      - 국내 특수학급 PBS 적용 (NISE, 2018; KABA, 2020~2023)
   3. 매체의 적절성 분석
      - WBI(인터넷 기반) 선정 이유: 실시간 데이터 동기화 필수
      - 모바일 PWA 선정 이유: 학생 자율 조작 + 오프라인 대응
   4. 개발 자료의 개요와 특성
      가. 적용 대상: 초등 특수학급 (6~7명), 전 학년
      나. 적용 교과: 국어, 수학, 일상생활 (행동 목표 연계)
      다. 주요 기능: PBS 3단계 지원 통합, 토큰경제, AI FBA 보조

Ⅲ. 자료 제작의 실제
   - PBS 3단계 → 시스템 기능 매핑 구조도
   - 행동 기능(SEAT) → 중재 전략 → 토큰 연계 흐름도
   - 주요 화면 설계 (교사 대시보드, ATM, 가게, 일기, TV)
   - AI FBA 분석·소거 감지 알고리즘 흐름도

Ⅳ. 자료 활용 방법
   1. 교사
      - PBS 목표 행동 등록 (기능·단계·강화 기준 설정)
      - 행동 발생 시 토큰 즉시 지급 (QR 또는 대시보드)
      - AI 제안 확인 및 수락/거절 기록
   2. 학생
      - QR 로그인 → ATM 잔액 확인 → 가게 교환 → 일기 작성
   3. 학급 TV
      - 전체 학생 현황 실시간 표시 (동기 유발)

Ⅴ. 기대되는 효과
   - 강화 즉시성 확보 → PBS 효과 극대화
   - 소거 폭발 사전 감지 → 교사 안전 대응력 향상
   - 누적 데이터 기반 FBA → 중재 전략의 객관성 확보
   - 학생 자기결정력 향상 (잔액 관리·교환 자율 선택)

Ⅵ. 일반화 방안
   - 학급 식별코드 방식: 추가 설치 없이 타 학교 특수교사 즉시 사용
   - PWA 오프라인 동작: 인터넷 불안정 환경 대응
   - 사용 가이드 영상 제작 및 에듀나비·에듀넷 공개 예정

참고문헌
   - Horner & Sugai (2010), PBIS.org, NISE(2018), PMC(2023), BACB 6th
```
