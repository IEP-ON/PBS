# Plan: 서식2_자료제작계획서 개요 재작성

## Context

현재 `자료 제작 개요` 섹션은 긴 줄글 한 단락으로 되어 있어 심사자가 한눈에 파악하기 어렵다.
실제 앱은 TV 순위표 / 말이야기 키오스크 / ATM / 학생 모바일 웹앱 / 교사 관리 화면으로
구성된 5-화면 체계인데 이 구조가 전혀 드러나지 않는다.
1페이지 안에서 목적·구성·흐름·기대효과가 시각적으로 분리되어 한눈에 읽혀야 한다.

## 수정 대상 파일

- `서식2_자료제작계획서.md`
  - `## 자료 제작 개요` 섹션만 교체 (나머지 표/메타 정보는 유지)

---

## 새 개요 구조 (4개 소절)

### ① 제작 목적 (2~3문장)

- PBS 현장 실행의 구조적 한계(즉각 강화·기록·분석 동시 수행 부담) 제시
- 디지털 토큰경제로 해결하고자 하는 방향 한 문장

### ② 자료 구성 (5-화면 체계 표)

| 화면 | 대상 | 핵심 기능 |
|---|---|---|
| **TV 순위표** | 학급 전체 | 실시간 순위·가게·주식 시세 상시 표시 → 동기 유발 |
| **말이야기 키오스크** | 학생 | 음성 녹음 → AI 텍스트·감정 변환 → 토큰 지급 |
| **ATM 키오스크** | 학생 | QR 토큰 리딤, 잔액 확인, 가게·주식 교환 |
| **학생 모바일 웹앱** | 학생 | 전 기능(통장·가게·주식·셀프체크) + 자기결정 |
| **교사 관리 화면** | 교사 | 행동 기록, 토큰 지급, FBA·AI 분석, 데이터 시각화 |

### ③ 실행 흐름 (화살표 흐름도)

```
교사 행동 기록 → 토큰 즉시 지급
       ↓
학생 ATM / 모바일로 교환 (가게·주식·저축)
       ↓
TV 순위표·가게·주식 실시간 갱신
       ↓
말이야기 키오스크로 하루 성찰 + 보상
       ↓
누적 데이터 → AI 행동 분석 → 교사 중재 전략 결정
```

### ④ 기대 효과 (3행 표)

| 대상 | 기대 효과 |
|---|---|
| 교사 | 즉각 강화·기록·분석 통합 → 실행 부담 감소, AI 보조로 데이터 기반 의사결정 |
| 학생 | 일관된 즉각 강화 + 자기결정(가게·주식·일기) → 기대행동 형성 및 자기조절력 |
| 학급 | TV 순위표·집단 강화 → 긍정적 학급 분위기, 타 학교 즉시 활용 가능 |

## 유의 사항

- 1페이지 이내 제한 → 모든 소절 합쳐서 A4 1장 분량 유지
- 표/화살표 흐름도 활용해 시각적 분리
- 전문 용어(PBS, FBA 등)는 괄호 풀어쓰기로 심사자 가독성 확보
- 기존 메타 표(구분, 출품분야, 자료명, 적용정보, 개인작) 및 하단 주석은 그대로 유지
