# 제46회 대구광역시 교육자료전 (2026)

> 주최: 대구광역시교육청 / 주관: 대구미래교육연구원

---

## 1. 목적

- 우수 교수·학습 자료 개발 활용 풍토 조성
- 교수·학습 자료 활용을 통한 교실 수업 방법 개선
- 전국대회 우수 실적 거양 및 우수 자료 일반화

## 4. 출품 자격 및 제한

- **자격**: 대구광역시교육청 산하 유·초·중·고·특수학교 교원
- **수량**: 1인 1점
- **공동 연구**: 4인 이내 (학교급 간 공동 허용, 직위가 다른 교원 간 불가 — 수석교사 제외)
- **보조자료**: 주자료 외 2개 이내 (단일 매체로 제한)
- **규격**: 가로·세로·높이 각 1m 이내

## 5. 심사 기준 및 배점 (100점 만점)

| 기준 | 배점 | 주요 내용 |
|---|---|---|
| 자료의 적절성 | 20점 | 교육과정 연관성, 제작목적 명확성, 교수-학습 효과 |
| 창의성 | 20점 | 참신성·독창성, 본인 직접 제작 여부 |
| 완성도 | 20점 | 기본 목적 부합, 제작 기술 정밀도, 매체 특성 활용, 견고성·편의성, 체계적 조직 |
| 교육에의 기여도 | 20점 | 교육문제 해결 접근, 교육효과 증진, 현장교육개선 기여 |
| 일반화 가능성 | 20점 | 제작 경비 적절성, 보급 용이성·경제성, 재료·제작방법 용이성 |

### 등급 기준

| 등급 | 점수 | 비고 |
|---|---|---|
| 특상(1등급) | 90~100점 | 전국대회 의무 출품 |
| 우수상(2등급) | 80~89점 | |
| 장려상(3등급) | 70~79점 | |
| 등외 | 69점 이하 | 표절·모작 포함 |

- **입상 비율**: 최종 출품작의 60% 이내
- **등급 비율**: 특상:우수:장려 = 1:2:2

## 6. 제출 서류 목록

### 4. 17.(금)까지 — 교데통 제출

- `<서식1>` 자료제작계획서 제출자 명단
- `<서식2>` 자료제작계획서 (1쪽 이내)

### 6. 19.(금)까지 — 교데통 + 인편 (대구미래교육연구원 교수학습지원부)

- `<서식3>` 출품자 명단
- `<서식4>` 출품신청서 (공동연구자 개인별 각 1부, 소속기관장 직인)
- `<서식5>` 교육자료 설명서 3부 + USB
  - 표지·본문 인적사항 표기 금지
  - USB 파일명: `성명_생년월일(6자리)_소속_주제명(분야)`
- `<서식6>` 서약서 1부

### 6. 30.(화) — 직접 반입

- `<서식7>` 교육자료 안내서 (모조 전지 1매, 전시대 벽면 직접 부착)
- 출품 작품 실물

## 7. 교육자료 설명서 작성 기준

- **분량**: 30쪽 이내 (초과 시 3점 감점)
  - 겉·속표지, 요약서, 목차 제외 / 참고문헌·부록 포함
- **규격**: A4 양면 컬러 인쇄, 좌철·제본 (스프링철·표지 코팅 금지)
- **여백**: 상·하·우 20mm, 좌 25mm
- **본문 글자**: 들여쓰기 10, 휴먼명조 11pt, 줄간격 140%

### 목차 예시 구조

```
Ⅰ. 자료 제작의 필요성 및 목적
Ⅱ. 자료 제작의 과정
   1. 제작 기간 및 절차
   2. 문헌 연구
   3. 매체의 적절성 분석
   4. 개발 자료의 개요와 특성
   5. 공동 연구의 필요성 및 업무 분담
Ⅲ. 자료 제작의 실제 (설계·도해 및 내용)
Ⅳ. 자료 활용 방법
Ⅴ. 기대되는 효과
Ⅵ. 일반화 방안
참고문헌
```

## 8. 시상 내역

### 개인상
- 교육감 상장 (특상·우수상·장려상)

### 단체상
- 최우수 2교, 우수 6교 내외
- 점수 계산: 출품실적 0.6점/작품 + 입상실적(특상 7점, 우수 5점, 장려 3점)

---

## 9. 전국대회 참가비 (교총 비회원)

- 출품자(인)별 90,000원
- 공동작 시 비회원 1인이라도 포함되면 납부

---

## 10. 유의사항

- 설명서 표지·본문에 소속·성명 등 인적사항 기재 금지 (불이익)
- 예비심사: **에듀나비 카피킬러 캠퍼스** 표절검사 (6어절 이상·1문장 이상 일치 기준)
- 표절·모작 적발 시: 등외 처리 + 이후 3년간 참가 자격 제한
- 대면 심사 시 공동작 출품자 전원 참석 원칙 (불참 시 불이익)
- 전시장: 무선 인터넷 제공 예정이나 오프라인 구동 환경도 반드시 구축
