## 1. PBS (긍정적 행동지원) 정의 및 프레임워크

### 1.1 공식 정의

> **"PBS(Positive Behavioral Interventions and Supports)는 학생의 행동·학업·사회정서·정신건강을 지원하기 위한 근거 기반 다층 지원 프레임워크이다. 모든 학생이 성공할 수 있는 긍정적·예측 가능·공평·안전한 학습 환경을 만드는 것을 목적으로 한다."**
>
> — PBIS.org (미국 PBIS 센터 공식 정의)

> **"문제행동에 접근하기 위하여 교사의 행동 변화를 요구하고, 모든 행동에는 그 행동을 유발하는 상황적 맥락에서 이유가 있기에 문제행동 발생을 예측할 수 있으며, 문제행동에 대한 처벌적인 접근보다 바람직한 행동에 집중하는 예방적 접근이다."**
>
> — 국립특수교육원 (NISE, 2018)

### 1.2 PBS의 핵심 특성

PBS는 **사후 대응이 아닌 사전 예방** 중심 체계다. 핵심 순서는 다음과 같다:

1. **기대 행동 정의 및 교수** — 바람직한 행동을 명시적으로 가르침
2. **긍정적 강화** — 기대 행동 발생 시 즉각·일관된 강화 제공
3. **데이터 기반 모니터링** — 행동 데이터를 수집·분석하여 의사결정
4. **개별화 지원** — 도전적 행동을 보이는 학생에 대한 FBA 기반 중재

> ⚠️ **주의**: PBS = "FBA + 전략 적용"이 아님. FBA는 PBS의 3차 지원(집중 지원)에서 활용되는 도구이며, PBS의 출발점은 **예방과 긍정적 교수**임.

### 1.3 PBS 5대 핵심 구성 요소

| 요소 | 설명 |
|---|---|
| **시스템(Systems)** | 팀 구성, 훈련, 코칭 등 지속 가능한 실행 기반 |
| **데이터(Data)** | 성과 선택·모니터링·평가에 활용하는 정보 |
| **실천(Practices)** | 근거 기반 중재 전략 |
| **성과(Outcomes)** | 행동·사회정서·학업 목표 |
| **형평성(Equity)** | 모든 학생의 소속감·성공 보장 |

## 2. PBS 3단계 지원 체계 (다층 지원 모델)

```
┌─────────────────────────────────────────┐
│  3차 지원 (집중 지원, 1~5% 학생)          │
│  FBA 기반 개별화 행동지원계획(BSP)         │
├─────────────────────────────────────────┤
│  2차 지원 (선별적 지원, 10~15% 학생)      │
│  소집단 지원, 체크인·체크아웃(CICO)       │
├─────────────────────────────────────────┤
│  1차 지원 (보편적 지원, 전체 학생 80%+)   │
│  기대 행동 정의·교수, 학급 전체 강화      │
└─────────────────────────────────────────┘
```

> 출처: Center on PBIS (pbis.org), 국립특수교육원(2018)

### 특수학급에서의 적용

특수학급(6~7명 소규모)은 단일 학급이 1·2·3차 지원을 **동시에** 실행한다:
- 전체 학생: 토큰경제 기반 1차 지원
- 일부 학생: 개별 PBS 목표 성과급(2차)
- 필요 학생: FBA + AI 중재 제안(3차)

## 3. 행동 기능 분석 (FBA, Functional Behavior Assessment)

### 3.1 정의

> **"FBA는 문제행동의 기저 기능(이유)을 파악하여 효과적인 중재 계획을 수립하기 위한 체계적 전략 집합이다. 문제행동 기술 → 선행사건·후속결과 확인 → 행동 기능 가설 수립 → 가설 검증의 절차를 거친다."**
>
> — ERIC/NCAASE (2019), Evidence-Based Practice Brief

### 3.2 행동의 4가지 기능 (SEAT 모델)

| 기능 | 영문 | 설명 | 예시 |
|---|---|---|---|
| **감각·자동** | Sensory / Automatic | 행동 자체가 감각적 강화 생산 | 손 흔들기, 흔들기 |
| **회피·도피** | Escape | 비선호 과제·상황 회피 | 과제 중 자리이탈 |
| **관심** | Attention | 성인·또래의 관심 획득 | 수업 중 소리지르기 |
| **선호물 접근** | Tangible / Access | 선호 물건·활동 획득 | 장난감 위해 울기 |

> 출처: BACB Task List 6th Edition; bcbamockexam.com SEAT Guide

### 3.3 ABC 모델

```
선행사건 (Antecedent) → 행동 (Behavior) → 후속결과 (Consequence)
```
- **선행사건**: 문제행동 직전 환경 자극
- **행동**: 관찰 가능한 구체적 행동
- **후속결과**: 행동 직후 발생하는 결과 (강화 or 처벌)

## 4. 토큰경제 (Token Economy)

### 4.1 정의

> **"토큰경제는 특정 행동에 대해 즉시 조건강화물(토큰)을 제공하고, 이를 나중에 백업 강화제와 교환하도록 하는 포괄적 강화 기반 행동중재다."**
>
> — PMC/BACB Certificant Survey (2023)

### 4.2 근거

- **연구 역사**: 80년 이상의 연구 축적 (ABA에서 가장 오래 검증된 절차 중 하나)
- **효과**: 지적장애·발달장애(IDD) 학생의 교육 환경에서 **가장 많이 사용되는 강화 방법** (칭찬 다음으로 2위)
- **적용 대상**: 자폐스펙트럼, ADHD, 지적장애 등 다양한 신경다양성 학생에게 효과적
- **효과 범위**: 동기, 참여도, 기술 습득, 학업·의사소통·사회적 행동 향상

> 출처: PMC — Common Practices in Token Economies (2023); Pace University Perspectives on Behavior (2020)

### 4.3 구성 요소

| 요소 | 설명 |
|---|---|
| **목표 행동** | 강화할 구체적 행동 명시 |
| **토큰** | 즉각 제공 가능한 조건강화물 (점수, 스티커, 화폐) |
| **백업 강화제** | 토큰과 교환 가능한 선호 물건·활동 |
| **교환 기준** | 몇 개의 토큰으로 무엇과 교환할 수 있는지 |
| **제공 일정** | 강화 스케줄 (고정비율, 변동비율 등) |

### 4.4 PBS와 토큰경제의 관계

토큰경제는 PBS 프레임워크 안에서 **강화 전달 메커니즘**으로 기능한다:
- 1차 지원: 학급 전체 토큰 적립 시스템
- 2차 지원: 개별 목표 행동 달성 시 추가 토큰
- 3차 지원: FBA로 확인된 기능에 맞는 토큰 기반 차별강화

## 5. 차별강화 전략 (Differential Reinforcement)

### 5.1 정의

> **"차별강화는 특정 행동에는 강화를 제공하고 다른 행동(문제행동)에는 강화를 보류하는 ABA의 행동 변화 기법이다. 처벌 없이 문제행동을 감소시키고 대체행동을 증가시킨다."**

### 5.2 유형별 정의

| 전략 | 약어 | 정의 | 주요 적용 상황 |
|---|---|---|---|
| **대안행동 차별강화** | DRA | 문제행동과 동일 기능을 수행하는 **대안행동** 강화 | 기능 대체 필요 시 (FCT와 병용) |
| **양립불가행동 차별강화** | DRI | 문제행동과 **동시에 수행 불가능한 행동** 강화 | 신체적으로 충돌하는 행동 있을 때 |
| **다른행동 차별강화** | DRO | 정해진 시간 간격 동안 **문제행동 부재** 시 강화 | 특정 대체행동을 지정하지 않아도 될 때 |
| **낮은비율 차별강화** | DRL | 문제행동이 목표 기준 이하의 **낮은 빈도** 로 발생 시 강화 | 완전 제거보다 감소가 목표인 행동 |

> DRA vs DRI 구분: DRA는 두 행동이 동시에 일어날 수 있음. DRI는 불가능함.

## 6. 소거 (Extinction)

### 6.1 정의

> **"소거는 이전에 강화되던 행동에 더 이상 강화를 제공하지 않아 행동 빈도를 줄이는 절차다."**

### 6.2 소거 폭발 (Extinction Burst)

> **"소거 절차 초기에 행동이 일시적으로 증가하는 현상. 자해 행동에 소거만 적용한 경우 62%에서 소거 폭발이 관찰됨."**
>
> — PMC (2023), Basic and Applied Research on Extinction Bursts

### 6.3 소거 적용 기준 (행동 기능별)

| 행동 기능 | 소거 적용 | 위험도 | 주의 사항 |
|---|---|---|---|
| 사회적 관심 | ✅ 가능 | 중간 | DRA/FCT 먼저 확립, 전체 교사 일관성 필수 |
| 회피·도피 | ✅ 가능 | 높음 | TM·FCT 병행 필수, 안전 계획 수립 |
| 자동적 강화 | 🚫 불가 | 해당없음 | 환경수정 + 감각 대체만 가능 |
| 선호물 접근 | ✅ 가능 | 중간 | NCE로 박탈 감소 후 FCT 확립 먼저 |

> ⚠️ **소거 단독 사용 금지**: 반드시 DRA 또는 FCT와 병행해야 함 (BACB 윤리 강령)

## 7. 기타 근거 기반 행동중재 전략

| 전략 | 약어 | 정의 | 근거 |
|---|---|---|---|
| 기능적 의사소통 훈련 | FCT | 문제행동과 동일 기능을 하는 적절한 의사소통 행동 교수 | WWC, BACB E-7 |
| 반응대가 | RC | 문제행동 발생 시 획득된 토큰 일부 제거 | BACB E-8 |
| 비수반 강화 | NCR/NCE | 행동과 무관하게 선호 자극을 정기 제공 (박탈 감소) | BACB E-6 |
| 촉구 및 소거 | PF | 단서(촉구) 제공 후 점진적 제거 | BACB E-3 |
| 행동형성 | Shaping | 목표 행동을 단계적으로 근사하게 강화 | BACB E-4 |
| 과제분석·연쇄 | TA | 복잡한 행동을 단계로 분해하여 순차 교수 | BACB E-5 |
| 자기모니터링 | SM | 학생이 자신의 행동을 스스로 관찰·기록 | BACB G-21 |
| 행동계약 | BC | 목표 행동과 결과를 명문화한 계약 체결 | BACB G-22 |
| 집단수반성 | GC | 집단 전체 행동에 결과를 수반 | BACB |
| 프리맥 원리 | PP | 고선호 활동을 저선호 활동의 강화제로 사용 | BACB E-2 |

## 8. 학술 근거 검증 결과 — 기존 문서 수정 사항

### 수정 필요 포인트

| 항목 | 기존 서술 | 문제 | 수정 방향 |
|---|---|---|---|
| PBS 정의 | "행동의 기능을 분석하여 전략을 적용하는 지원 체계" | PBS 전체를 FBA 중심으로 설명 → PBS의 1차 예방 성격 누락 | "예방·교수·강화를 중심으로 한 다층 지원 체계, 도전적 행동에는 FBA 기반 개별화 지원 제공" |
| 토큰경제 위치 | "PBS 실행 수단" | 맞으나 부연 부족 | "PBS 내 강화 전달 메커니즘이자 1~3차 지원 전반에 적용되는 행동주의 강화 절차" |
| 심사기준 대응 | "교육과정 내 PBS 직접 구현" | PBS는 교육과정 내 단원이 아님 | "2022 개정 특수교육 교육과정 사회적응·일상생활 교과 교수-학습 지원" |
